# ── Sandbox /etc/hosts entries ───────────────────────────────────────────────
#
# WHAT: maps the sandbox *.home.arpa hostnames to the k3s ingress node so your
#       Arch box (the only machine that can reach the libvirt-NAT VMs) resolves
#       them. .home.arpa is reserved/internal — no public DNS will ever answer
#       it, so YOU provide the answer here.
#
# WHY /etc/hosts (not Pi-hole yet): the VMs live on libvirt NAT (192.168.122.x),
#       reachable only from this host. /etc/hosts is checked BEFORE any DNS
#       server (nsswitch: files → dns), so it works regardless of resolver
#       (systemd-resolved / NetworkManager). Graduate to Pi-hole local DNS once
#       you're on the HP + real LAN and want phones/other devices to resolve too.
#
# IP:   192.168.122.165 = the MASTER VM (where Traefik/Gateway listens on :443).
#       Verify with:  sudo k3s kubectl get svc -n kube-system traefik
#       ...and change the IP below if yours differs.
#
# APPLY (on the Arch box):
#   sudo sh -c 'cat >> /etc/hosts' < ansible/sandbox-hosts.txt
#   # (or just paste the lines below into /etc/hosts by hand)
#
# REMOVE later: delete these lines from /etc/hosts.
# ─────────────────────────────────────────────────────────────────────────────

# ── via the MASTER node ──────────────────────────────────────────────────────
192.168.122.165   vault.home.arpa

# ── via the RASPBERRY PI / Rock 4b+ worker ───────────────────────────────────
# Every k3s node runs the ingress load balancer (svclb), so Traefik also answers
# HTTPS on the Pi's IP — same cert, same routes, different entry node. Point a
# hostname here to reach the cluster through the Pi.
#
# ⚠️ Set <RASPBERRY_PI_IP> to the Pi's real address. Find it with:
#      sudo virsh net-dhcp-leases default        # (if it's a libvirt VM)
#      ip -4 addr show                            # (on the Pi itself)
#      sudo k3s kubectl get nodes -o wide         # INTERNAL-IP of the worker
#
# NOTE: listing the SAME hostname on two IPs = DNS round-robin (redundancy, not
#       real load balancing). Fine for a sandbox. Or give the Pi its own name.
